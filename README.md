# Study Planner

A simple study planner and to-do list made with HTML, CSS, and JavaScript.

## Features

- Add a task with a due date.
- View added tasks under "Your Tasks."
- Delete a task when you are finished with it.

## Setup

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.

No extra installation or dependencies are required.

## How to Use

1. Type a study task in the task field.
2. Choose a due date.
3. Click **Add Task**.
4. Click **Delete** next to a task to remove it.

## Project Files

- `index.html` contains the page structure.
- `styles.css` contains the page design and responsive styles.
- `script.js` adds and deletes tasks.
